# Формальна специфікація мови SIPL (`CORE-01`)

## 1. Загальна характеристика
**SIPL** (*Simple Imperative Programming Language* / *Structured Imperative Programming Language*) — модельна структурна імперативна мова програмування, що використовується в курсі «Теорія програмування» для формалізації синтаксису, композиційної семантики та доведення коректності програм.

## 2. Синтаксичні категорії та метазмінні
Відповідно до Таблиці 1.3 підручника М. С. Нікітченка та Практичної роботи №1:

| Метазмінна БНФ | Синтаксична категорія | Символ у теорії | Вузол в AST (`sipl.ast`) |
| :--- | :--- | :--- | :--- |
| `<програма>` | `Prog` | $P$ | `Program` |
| `<оператор>` | `Stm` | $S$ | `Assign`, `Seq`, `If`, `While`, `Block`, `Skip` |
| `<вираз>` | `Aexp` | $a$ | `Num`, `Var`, `BinOp`, `ParenAexp` |
| `<умова>` | `Bexp` | $b$ | `CmpOp`, `NotOp`, `OrOp`, `ParenBexp` |
| `<змінна>` | `Var` | $x$ | `Var` |
| `<число>` | `Num` | $n$ | `Num` |

## 3. Продукційні правила БНФ
* **`P1` (`NP1`)**: $P ::= \mathbf{begin}\ S\ \mathbf{end}$
* **`S1–S6` (`NS1–NS6`)**: $S ::= x := a \mid S_1 ; S_2 \mid \mathbf{if}\ b\ \mathbf{then}\ S_1\ \mathbf{else}\ S_2 \mid \mathbf{while}\ b\ \mathbf{do}\ S \mid \mathbf{begin}\ S\ \mathbf{end} \mid \mathbf{skip}$
* **`A1–A6` (`NA1–NA6`)**: $a ::= n \mid x \mid a_1 + a_2 \mid a_1 - a_2 \mid a_1 * a_2 \mid (a)$ *(консервативне розширення практикуму також включає `div`, `mod` та символ `×`)*
* **`B1–B5` (`NB1–NB5`)**: $b ::= a_1 = a_2 \mid a_1 > a_2 \mid b_1 \lor b_2 \mid \lnot b \mid (b)$ *(консервативне розширення практикуму включає `>=`, `<`, `<=`)*

## 4. Опис лексики та пріоритетів операцій
* **Ключові слова (зарезервовані)**: `begin`, `end`, `if`, `then`, `else`, `while`, `do`, `skip`, `div`, `mod`, `not`, `or`.
* **Ідентифікатори змінних (`Var`)**: `[A-Za-z_][A-Za-z0-9_]*`, що не збігаються з ключовими словами.
* **Цілі числа (`Num`)**: `... -2, -1, 0, 1, 2 ...`.
* **Пріоритети операцій (у порядку зменшення, усі бінарні арифметичні та булеві операції лівоасоціативні)**:
  1. Множення та ділення: `*`, `×`, `div`, `mod`
  2. Додавання та віднімання: `+`, `-`
  3. Операції порівняння: `=`, `>`, `>=`, `<`, `<=`
  4. Заперечення: `¬` (або `!`, `not`)
  5. Диз'юнкція: `∨` (або `||`, `or`)
  6. Присвоювання: `:=`
  7. Цикл: `while ... do ...`
  8. Умовний оператор: `if ... then ... else ...`
  9. Послідовне виконання: `;`

## 5. Приклади коректних і некоректних програм

### Коректна програма (Варіант 8 — сума геометричної прогресії)
```pascal
begin
  R := 1;
  T := 1;
  while N > 0 do
  begin
    T := T * 2;
    R := R + T;
    N := N - 1
  end
end
